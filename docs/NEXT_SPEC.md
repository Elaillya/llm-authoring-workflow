# 自然表达、多样性记忆与选题入口：独立优化草稿

基准：54b050cd87b71d8d7e3aae9b9681f42426902ad4（3.0.0）。用户于2026-10-14授权先实现以下优化；尚有后续要求。本副本没有remote；本轮不更新任何既有工作区、不修改正式工具仓、不推送GitHub。

1. 新题先二选一：计算机科学、商科；再询问对应子方向，再选现有三种题型。CS四类是日常AI/学生问题、大学课程学习实验、研究生科研、真实生产开发。日常类语言贴近普通人，课程可使用课程术语，科研与生产允许专业性但必须有真实目标和约束。具体课程/技术栈不是用户额外必填项，已有选择直接记录。
2. 商科提供与可靠参考库对应的七个子方向；资料库含实际查验的一手公开来源索引及原创机制卡，明确适用条件、反例/边界、稳定性，不收录供应商密钥、个人题目、模型回复或大段教材原文。每题仍需查验适用性与当时事实，库不是已验收题库。
3. 题面自然、明确，保留必要事实；固定Insight三字段的内部数据结构保持。专业度随所选情境变化，不能为避免AI感而强行口语化专业题，也不能所有题都套同一第一人称/对比句式。词表仅提示，不能自动判定是否自然。
4. 父工作区local/下的SQLite保存个人题目记忆（题面、Insight、考点、选题画像、状态与出处），独立于全局Codex记忆，跨题目/窗口共享。begin/设计时提供既有题目与机制索引；候选阶段比较题面、Insight和考点文本及语义画像，不仅比较标题、领域或同义替换。
5. 查重使用不需API的本地文本相似度与机制/评分目标标签召回，辅以作者/助手逐条语义复核；不宣称确定性算法能理解所有同义改写。完全重复跨题prompt硬阻断；高相似候选必须改题或有可核对的实质区别解释。仅共享通用格式或术语不等于同题，明确记录比较依据。自然表达和语义复核由助手完成，不新增用户审批流程。
6. design-check/template/review与candidate-reserve入口串入新题冻结；检查绑定题目、来源笔记和当前其他题记忆快照。SQLite事务防并发漏写，同一任务修订/旧题续作保留；失败与放弃候选可记录。初次memory-sync只读取普通任务目录的冻结记录，不读取API配置、回复、截图、归档或全局记忆；legacy冻结内容不改写。
7. 旧已冻题仍可读/续作，不强迫重新选择分支或改原件。旧未冻结请求可显式升级选择；新题需完整新选择及设计复核。当前手动Seed优先、GPT/Claude门槛、Arena与五模型排序及六MD交付规则保持。
8. 测试覆盖两菜单/CS四分支/商业来源卡绑定、自然风格提示不误禁专业术语、三个维度的查重、同义画像召回、通用结构非误判、同题修订、并发预留、快照过期、原件/来源变更、历史导入保护及手动完整流程。仅合成数据；测试环境在/tmp。本轮结果保存至独立staging目录，说明尚未部署。
