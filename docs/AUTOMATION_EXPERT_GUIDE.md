# 专家使用说明：自动化分支

本说明只列出专家需要准备和操作的内容。自动化分支到Arena入口交接；Arena操作、最后核对和平台正式提交由专家完成。

## 开始前准备

| 准备项 | 需要达到的状态 |
|---|---|
| 流程仓库 | 已取得当前版本，并在agent中打开仓库目录。首次使用可以先让agent检查并准备本机依赖。 |
| ego-lite浏览器 | 已安装并启动，本机ego-browser技能与命令可用。准备一个供本次做题使用的空间，记下空间名称。 |
| 做题平台 | 在上述空间内登录，打开目标题目的提交信息填写页。确认题号正确，保留页面。 |
| pi-web | 服务已启动，准备好本次实际访问地址和服务端的答题项目目录。地址不设默认值；远程服务请提供服务端目录。 |
| 答题模型 | pi-web界面中能选择本项目要求的Seed、GPT、Claude型号；所需推理档位可用，服务能够正常生成回答。型号要求以当前仓库说明为准。 |
| 选题范围 | 准备题号，以及计算机科学、商科、生活娱乐中的一个大方向。可同时给出专业范围或排除项。 |

答题项目使用单独目录，不放出题草稿、Insight、考点或其他模型的回答。若需要配置pi-web模型服务，在pi-web自身配置，不把密钥粘贴到做题聊天中。自动化网页分支通常不需要另行填写平台Cookie文件；登录和验证码由本人处理。

首次依赖检查可直接发送：

```text
请检查当前仓库自动化分支所需的本机依赖，以及ego-lite和ego-browser是否可用；缺失部分请协助准备。
```

## 启动一道新题

完成登录和服务启动后，向agent发送以下口令，把占位内容替换为实际值：

```text
按本仓库AGENTS.md使用自动化分支试做一道题。
题号：<题号>
大方向：<计算机科学／商科／生活娱乐>
专业范围或排除项：<有则填写，没有则写由你选择>
请在workspaces下创建本题工作区。
ego-lite空间：<空间名称>
做题平台页面：<当前题目填写页URL>
本次pi-web完整服务地址：<协议、主机、端口及适用的路径前缀>
pi-web服务端答题项目目录：<实际目录>
请自主推进到Arena入口，需要我处理登录或其他明确事项时再提示我。
```

以agent返回的题目工作区和文件链接为准。每题使用自己的聊天和工作区；已有题目继续原任务，避免另建同题副本。运行期间保持浏览器与pi-web服务可用，在接管提示出现前避免同时编辑目标题目页面。

## 到Arena入口后

1. 阅读agent给出的交接说明，核对目标题号、平台质检的实际结果，以及是否有异议或异常备注；需要纠正时先告诉agent。
2. 在平台按实际要求完成“确认后继续”等人工操作。使用agent提供的题面文件，在Arena的Search + Battle新会话取得另外两个模型的回答。两者不得重复，不得与前三个模型相同，也不得为GPT或Claude系列；平台有更新要求时以当前验收要求为准。
3. 打开agent给出的两个Arena填写文件，按文件格式填写真实型号和完整Markdown原回复，保留原有代码块及格式。同时按平台要求留存、提交Arena截图。
4. 告诉agent：“Arena两份回答已填好，请继续五模型评估、排序和交付。”
5. 使用最新交付链接核对提交信息及五份原回复，将最终材料填入平台，检查附件与备注后本人正式提交。

## 中断与特殊情况

| 情况 | 专家如何处理 |
|---|---|
| 登录过期或出现验证码 | 在原浏览器空间中完成登录或验证，然后告诉agent“已处理，请从原断点继续”。 |
| pi-web无法连接 | 确认服务仍在运行，提供本次可访问的完整地址；地址或答题目录改变时明确告知agent。 |
| 模型测试报错、目标型号或推理档位不可用 | 提供界面完整报错及配置是否发生变化，请agent先排查；不要直接用其他型号替代。 |
| 服务等待很久、发送后断线、检查没有明确结果 | 保留原会话和页面，告诉agent当前现象，请其核对原请求状态；不要自行再次发送或连续点击质检。 |
| agent请求接管浏览器 | 只完成提示所需的人工作业，完成后在原聊天说明结果；保留原空间和标签页。 |
| 候选尝试用完，仍没有可用题目 | 根据agent给出的原因，选择调整范围、增加尝试预算或结束本题。可说：“改为<范围>，继续本题。” |
| 对考点、模型判断或质检结论有不同意见 | 指出具体条目、原文和专业理由，让agent核对并修订或记录异议；异常或跳过不等于通过。 |
| 需要额度以外的再次获取回答 | 明确指定允许替换的模型和次数。例如：“本次允许Claude再获取一次，保留旧回复后统一重评。”日常额度内无需逐轮授权。 |
| 聊天中断或更换窗口 | 提供原题号和工作区路径，发送下方恢复口令。 |
| 提交文件打不开或出现权限拒绝 | 将文件路径和错误原文发给agent，要求按仓库权限修复工具处理；保留原文件。 |

恢复口令：

```text
继续题目<题号>的自动化流程。
原工作区：<本题工作区路径>
请先读取状态与工作记录，从原断点接续，保留已有题目、回复、截图和质检结果。
本次pi-web地址或浏览器空间的变化：<有则填写，没有则写未变化>
```

最终材料请使用agent最后提供的交付版号。需要修正已生成材料时，直接说明具体问题，由agent保留旧版并提供新链接。
