## 证据和兼容边界

- 保存确认目前仍依赖已观察到的本次暂存时间变化或已有匹配回执。没有实测到可独立采用的额外保存完成信号，因此同秒保存/基线缺失返回save_unconfirmed，不把字段一致当保存成功。此部分是安全的有限返回改进，尚未完全解决同秒保存的自动确认。
- 会话准备支持标准details和具有展开语义的处理详情按钮；本轮未对新适配器完整重跑实站截图链路。遇到不同结构仍先观察，保留已有低层截图入口。
- 正常/异常反馈组合与最终回读已用合成材料验证；实站只读观察到URL与实际题目ID不同。用户确认这可属正常站内切题，已移除URL一致性的硬性要求；未为验证而改题、暂存、生成或发起质检。
- 新导入会建立来源关联；旧题不补造新关联。旧式手工来源、异常、异议和目视检查记录缺少通用证据格式时，只能说明未核验范围，不保证自动解释全部历史定制文件。
- 用户重跑接收要求前次已结束记录、相同依赖输入、恰增一次调用和用户真实说明。缺少证据时返回未知，不用新增检查补证明。
- 关闭本地API门禁与是否执行网页检查分别处理；网页结论和agent处理决定仍分离。质检自动技术重试不在本轮授权范围。
- 历史题目、原回复、交付和目录未迁移或覆盖；本轮未对真实题目重新导出。工作区权限继续继承父目录。

## 验证

配方定向测试45项通过，最后反馈接续修订后相关24项再次通过；证据/导入/目录和Windows入口最终定向13项通过，包含新增platform-fields入口用例。

完整回归324项，耗时765秒，3个失败、24个错误；与此前319项基线逐项比较，失败集合完全一致，没有新增或消失。剩余问题包括Windows符号链接权限、旧signal/render/provider兼容和共享记忆路径等，不能声称全量通过。完整回归启动后新增的CLI用例及小幅接续修订已由上述定向测试覆盖。

完整日志留在本地维护目录，公开文档仅记录通用结果。浏览器仅只读核验，不调用付费模型，不新增平台检查，不进行正式提交。

另外对两道既有题做了本地证据只读兼容检查：可读取已保存的考点通过与三模型截图上传回执；部分题目关联、达成性及目视记录依赖旧手工补充，自动读取会注明未核验范围。未修改原材料、重新导出或追溯使旧交付失效。

用户校正目标规则后，新增URL滞后/缺失但实际目标正确时允许读写的用例，保留实际目标错配拦截；相关目标和阶段配方24项通过。URL差异不再作为异常或额外确认条件。
