# 3.3.0 生活爱好类与分层选题资料库

用户要求在计算机科学、商科之外增加生活爱好类，提供不限两层的合理分类和丰富可靠的资料集，沿用当前完整出题流程。

- 本地大类名称为“生活爱好类”；甲方原规则领域清单中的对应标签为“生活爱好”。计算机科学四分支、商科七分支及已选题目均保留，不从题号推断方向。
- 采用主题树＋横向场景标签。五条主干：兴趣爱好、活动与出行、日常生活、个人生活规划、学生学习与课余生活。支持兴趣爱好/文艺/音乐/摇滚、兴趣爱好/运动/跑步、兴趣爱好/运动/球类/乒乓球等路径。用户可逐层选、直接指定细类，或确认停在当前范围由助手细分，不强迫回答整套分类问卷。
- 目录节点保留稳定ID、受众与出题指引；新菜单按层显示，不一次倾倒整棵树。选择记录路径与确认状态。冻结前确认范围，拒绝跨域/错配子方向；旧已冻结题的选择与证据不改写。
- 资料库为人工转述的一手资料索引、独立机制卡和明确标注的构造情境种子，不是实际模型测评集。逐来源记录精确URL、机构、阅读日期、实际读取范围及边界；失败抓取和仅搜索摘要不得记为已读。
- 机制卡包含真正改变答案的因素、机制、适用条件、不可外推处、常见误区、可独立判断的考点目标、构造场景及关联来源。主题匹配能继承父节点资料，同时允许在选定大范围内使用更细主题卡；检索分页、返回机制索引和覆盖信息，避免长文本淹没上下文。
- 缺口由助手研究并以公共条目同结构写本题drafts/lifestyle-supplement.json，新增ID不覆盖公共卡；公共与私有资料均可分页检索并绑定复核哈希。新生活候选须绑定匹配范围的机制卡和实际核验来源，写本题sources.md；质量复核绑定资料库内容哈希。不能把卡片原样当合格题，也不能仅换主题重复同一Insight。保留全部本地跨题记忆与语义复核。
- 个人审美、生活方式、人生偏好不能被当成唯一正确答案。需给定目标、事实和限制，用可复核机制形成Insight；医学治疗、临床心理、投资与法律结论不作默认生活题。涉及食品/清洁/户外的一般规划按官方边界；地区规则、场地开放、天气、价格等出题时重新核验。
- Seed优先、完整三模型门槛通过后才并行质检、五模型原文手动MD、同输入约束、纯文本作者字段、单条考点独立判定、具名严格并列等全部保持。新增领域映射按缺省值读入，不覆盖现有私有映射或Cookie；本轮不实际调用平台或模型。
- 完成资料、工具接入、合成回归和独立复核后，仅更新新版父工作区及通用仓库；保留原题、选择、负结果、原回复、判断、质检证据、交付与旧父工作区。
