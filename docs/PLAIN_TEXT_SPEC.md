# 3.2.0 题面与纯文本表达

本轮范围为用户2026-10-15明确提出的五项修改；此前要求相冲突时以本轮为准。

1. 新生成的三模型prompt.md和Arena的arena-prompt.md逐字节等于冻结question.prompt，不追加格式指令、前后缀、说明或换行。准备和导入均核对题面。已有旧版采集证据按原合同兼容读取，不改写原文或伪称其发送内容相同。尚未填写、未采集的旧提示文件可备份后同步为新格式。
2. Insight允许非空纯文本字符串，也兼容旧机制/优先级/结论对象。新模板默认字符串；单段、因果解释、对比或分层均可，不强制标题。校验、平台检查、本地题库、免复检表达优化和交付须均能处理这两种形态。
3. Insight、两类核心考点、达成性与备注、决定性核心考点达成性排序说明和最终排序备注以纯文本呈现；沿用提交信息.md文件名，内容用普通字段标签和段落，不用Markdown标题、列表、强调、表格或代码块。五个模型原文仍各自保存为MD，逐字节不变。JSON及原始证据保留。
4. 每条考点只判断一个明确、可核对的事实、关系或行动；可分别给出不同达成判断的要求应拆开。不能机械按“和/并且”切分真实的单一关系，不能为改变排名而增加重复点；已有冻结考点不自动重写，修改须统一重评。
5. 排序说明简洁写清具体考点达成差异和原因，取消500字下限；保留五模型覆盖、评估绑定、具名排序、决定性优先、同梯队总考点计数及同分并列。模板不重复长篇原文引用，证据仍在达成性记录中。
6. Insight组织形式按题目推理和受众选择；避免固定三段模板，题库比较实际机制与评分要求。模型原文中的完整Markdown代码块应按原件接受，截断的未闭合代码块仍拒绝。
7. 用户补充：不论组织形式，Insight始终突出真正改变结论或行动主线的决定性因素，说明为何关键。核心考点减少已知背景，只保留影响判定的必要条件和核心事实。

仅部署到/srv/llm-authoring-lab-v2及所含任务，旧父目录继续旧流程。保留已有选择、题面、回复、判断、质检、交付、Cookie和题库；同一共用配置不重新导入。本轮不调用模型或平台检查。发布通用源码至Elaillya/llm-authoring-workflow，不包含私人题目与登录态。
