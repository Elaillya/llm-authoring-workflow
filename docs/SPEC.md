# 第一轮出题工具实施约定

2026-10-12。用户要求按第五期拆为第一轮出题与第二轮质检/排序，本次只实现第一轮，同时交付可发布GitHub的通用工具包和当前服务器可用的独立工作区。

第一轮范围：先询问三种题型；首次缺配置时提示填写三个指定模型；计算机科学场景、问题、关键事实/限制由助手生成并核实；题面≤100字符；Insight的机制/优先级/结论；明确决定性及可选非决定性点；先冻结再采集；Seed 2.1 Turbo、GPT-5.6 sol、Claude Opus 4.6完整Markdown与截图；逐项判断全部决定性点；区分度；作者自查；第一轮交接。第一轮只需三个模型，不含Arena或排序入口。

自查依据第五期新方案及验收反馈：题型匹配、自然表达、真实且稳定场景、必要条件与无提示泄露、Insight四标准/优先级/结论、考点具体可判定与优先级拆分、Insight和考点不同表达、来源与设定诚实。按题型检查选择落在候选内、推荐从场景推导有限画像、How-to步骤主线可执行。

缺回复不是不满足。每个模型全决定性通过才记整体达成，Seed未达成且GPT或Claude至少一个达成为出题门槛。先记录候选题面/Insight/考点再测Seed；Seed全部达成则修订候选，未达成才调用GPT/Claude，最终交付仍需三个完整结果。通过门槛与自查后锁定提交版。非决定性点无时字段“无”；第一轮保留标准，达成性只评决定性。判断和自查绑定冻结版本与原文哈希；不以模型品牌、长度或格式作内容评分。

已有客户修复的JSON/SSE、总时限与中途原流保存复用；成功后等待完成事件不等EOF；不自动重复付费。截图来源清楚、版号与全文可见，字体离线加载、外部资源阻断。准确记录请求和实际返回ID，不能静默换版本。原回复、原响应、图片和版本可核哈希。

源码通用、无制作者绝对路径依赖、无真实API配置/密钥/个人题目/运行记录。工作区从模板创建自己的私有配置和每题Git；已有旧工作区和任务保留。当前服务器可显式绑定已存在的只读依赖环境以节省空间，正常GitHub用户通过setup建立自己的环境。

交付包含全部出题字段、三个模型的完整原文/图/判断及来源、作者自查、handoff.json和manifest。导出目录不可覆盖，文件先暂存再发布。handoff明确第二轮独立质检待进行；平台上传、真实第二轮与最终验收不在本次实现范围。

验证应覆盖首次空配置提示/已有配置不再提示、每新题必须选题型、三模型导出可行/缺证据禁止、可选点无、不同题面/考点阻断旧证据、图片与原文哈希、发布包内容/密钥隔离、从带空格的新路径解压后独立创建工作区。真实模型重跑仅在出题任务中必要调用，本次软件验证不需收费调用。
