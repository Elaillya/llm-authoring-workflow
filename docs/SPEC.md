# 完整出题工具实施约定

2026-10-13 用户更新覆盖旧版上下轮拆分：同一workflow完成出题、三模型验证、Arena两个随机模型和五模型排序，不设置独立质检或返修审批阶段。既有作者自查和出题门槛保留。

- 保持新题先选三种题型、首次三模型配置提示、默认计算机科学场景由助手生成并核实。Seed默认2.1 Turbo，GPT-5.6 sol/Claude Opus 4.6中高推理。候选先冻结，Seed未全部决定性达成再验证GPT/Claude，至少一个全部达成。
- 旧题的REQUEST、CURRENT、冻结题面/Insight/考点、API原文、失败记录、截图、判断、自查和旧交付均保留；升级只更新侧栏Skill、说明和工具入口，备份旧说明，不收费重取三个模型。
- 工具创建arena-input/rNNNN/model-4.md和model-5.md，用户填写揭晓的完整model_name及完整Markdown回复。只接收这两份MD，不要求Arena图片、额外配置或用户创建文件。Search、Battle、新会话和随机性按项目要求提示，工具只声称收到用户MD，不冒称独立页面核验。
- 模型4/5不得相同、不得与前三个相同、不得属于GPT/Claude系列。占位输入、过期题面绑定、截断Markdown和被改写原件均阻断导入或完成。已有回复不覆盖，重复导入相同文件幂等。
- 五模型评估沿用schema_version=1及既有冻结/原文哈希。模板复制前三个模型已有的决定性判断；辅助考点需要对五模型统一补评，不得把缺判断记作未满足。
- 排序严格按第五期：全部决定性达成是第一梯队，未全部达成是第二梯队；同梯队比较全部核心考点满足数，同数并列。显示模型1–5，顺序Seed/GPT/Claude/Arena4/Arena5。理由为总结＋逐模型具体考点及依据，不少于500字；排序记录绑定当前完整评估哈希，禁止私改次序。
- export生成五份原文、题目/Insight/两类考点、全部判断、排序与理由、三份既有API图、证据和manifest。Arena图记为用户单独提交，不纳入文件存在门槛。旧三模型导出是checkpoint，不是完整提交；最终output使用新目录且原子发布，拒绝覆盖冻结或证据目录。
- 功能需通过合成端到端测试、旧题接续保护测试、同分并列/梯队/辅助点排序测试、输入完整性与绑定测试。发布包仅来自已提交通用源码；原个人配置和题目不进GitHub。同步公开仓库Elaillya/llm-authoring-workflow，沿用远端历史正常推送。
