# 3.6.0 显式跨父工作区共享题库

用户要求新父工作区复用v2题库和失败经验，后续两边写同一份数据。仅改本地共享记忆及接续指引；不重置正在进行的三个任务，不发模型/平台请求，不发布GitHub。

- 默认仍各父目录独立。显式配置local/shared-memory.json，声明schema_version=1、owner_workspace绝对路径、members全部父工作区绝对路径。各父目录.authoring-workspace.json持久标记shared_memory_required=true，配置丢失时仍能识别已加入共享组；全部成员均已标记且互相配置一致才生效，所有者也必须是成员。
- 所有成员的题库、失败观察与复核统一读写所有者local/question-memory.sqlite3，直接使用同一规范路径和SQLite事务锁；不复制同步、不使用数据库软链接。
- 已有数据先备份、校验、无损合并。保留v2全部条目、事件及复核历史，也保留v3新增失败观察；ID冲突且内容不同必须停止，不能覆盖。迁移为本次本地运维，不自动扫描或合并陌生数据库。
- sync扫描所有明确成员中的正常任务冻结版本；原TASK.memory_id、失败证据/引用路径不重写。成员之外仍隔离，禁止路径或软链接逃逸。配置损坏、不一致、所有者数据库丢失时报错，不能退回或新建空库。
- context/sync明确返回共享范围、数据库路径、成员。认可/待确认/有异议分开，原失败信任与引用校验保持；全部新观察和复核也自动写同一库。
- 新增跨父候选参与设计查重和快照失效；预留/冻结在同一写锁内重查，防止两个父窗口同时凭旧快照放行。已冻结题目、原回复、判断、质检记录和交付不变。正在做的未冻结任务恢复后刷新共享上下文、重做设计差异复核即可，不能自动重置题目。
- 合成测试覆盖默认隔离、双向写读、共享失败复核、跨父冻结导入/并发预留/快照失效、路径与配置错误。部署后备份回执、两边相同数据库路径和原始行/题目文件哈希核对。
