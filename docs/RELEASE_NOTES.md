# 3.1.0（2026-10-15）

- 新题选择计算机科学或商科及对应子方向；结合专业参考资料生成自然题面，父工作区私有题库辅助比较场景、Insight及考点，减少同质化。
- 题面与Insight先做平台难度标签检查；三模型原文、判断及备注齐备后，用qa-run models并行质检考点与达成性。正常请求等待至完成，客户端不设时限；保留独立结果、有效缓存和未知状态防重发保护。
- 门禁满足后先发Arena填写链接。三项实际通过的表达建议随后离线优化，保持题面、含义及判定，优化后不重检；可核对的错误内容结论生成证据异议及可复制备注。
- 模型回复仍全部手动Markdown，先Seed，再按门槛收GPT/Claude，最后Arena两份与具名排序；截图由用户另交，交付保持一份提交信息和五份模型原文。

更新保留已有题目、原回复、评估与交付，先备份侧栏说明。平台登录态和本地题库属于私有工作区，不进入公开仓库；旧任务按原合同接续。177项合成回归通过，真实平台检查在实际出题时进行。
